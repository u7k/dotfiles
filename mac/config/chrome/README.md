# Chrome

## Vimium C

Install Vimium C, open its **Options** page, select **Exported file** next to
**Import settings**, and choose `vimium-c.json`.

The imported mappings use:

- `q` for the previous tab
- `w` for the next tab

Vimium C does not run in text fields, on `chrome://` pages, or on some other
extension pages.
